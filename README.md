# Постироничный мем-бот

Кидаешь боту фото — получаешь его же с рандомной постироничной надписью.
Бот локально ищет лица и визуально свободные участки, поэтому подпись может
оказаться сверху, снизу, сбоку или посреди кадра, но не на лице.
Плюс две кнопки: любой пользователь может пополнить базу фраз или сделать
мем со своим текстом на своём фото.

## Что внутри

- `bot.py` — сам телеграм-бот (aiogram 3), кнопки и все сценарии
- `memegen.py` — рисует текст на фото (Pillow)
- `smart_layout.py` — локально ищет лица (OpenCV), оценивает загруженность
  кадра и выбирает свободное место для текста
- `phrasebank.py` — база фраз + логика "не повторяться, пока не пройдём всю базу"
- `phrase_categories.py` — автоматически раскладывает каждую фразу в одну из
  четырёх колод: обычную, абсурдную, жёсткую или интеллектуальную
- `phrases.txt` — сама база из **6000+ фраз**: ручные, сгенерированные
  комбинаторно и классические демотиваторные подписи. У каждого шаблона
  генератора свой жёсткий лимит (обычно 20–45 штук), чтобы один паттерн не
  заполнял собой половину базы и не выглядел как раскопированный ИИ-слоп.
  Согласование рода и падежа в сгенерированных строках проверено
  программно. Дописывать можно бесконечно — через кнопку в боте,
  командой `/add` или руками в файл.
- `phrases_uncensored.txt` — отдельная редакционная пачка новых фраз; при
  загрузке она проходит ту же рубрикацию, что и общая база
- `generate.py` — сам генератор фраз, можно менять банки слов/шаблоны и
  гонять заново на любой объём.
- `fonts/` — пять кириллических стилей для случайных мемов: Oswald, Roboto
  Condensed, Rubik, Inter и PT Serif Italic. **Важно:** настоящий Impact не
  поддерживает кириллицу, поэтому вместо него используются близкие по характеру
  гарнитуры.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

1. Получи токен бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. Задай переменную окружения и запусти:

```bash
export BOT_TOKEN="твой_токен"
python bot.py
```

Бот стартует в режиме polling — не нужен ни сервер, ни вебхук, можно гонять
хоть с ноутбука. Для постоянной работы разверни на любом VPS/сервере, например
через systemd или `screen`/`tmux`, либо через Docker (см. ниже).

Остальные переменные окружения, все необязательные:

- `ADMIN_ID` — твой telegram id: только ему приходят заявки из предложки с
  кнопками Одобрить/Отклонить/Изменить текст. Без него модерация не работает.
- `CHANNEL_ID` — канал (`@my_channel` или `-100...`), куда уходят одобренные
  заявки. Он же используется для проверки подписки: пока переменная не задана,
  бот пускает всех, как только задана — требует подписку на канал.
- `SUBSCRIPTION_CHANNEL_ID` — если проверять подписку нужно в другом канале;
  без неё используется `CHANNEL_ID`.
- `POST_CHANNEL_ID` — если публиковать одобренные заявки нужно в другом канале;
  без неё используется `CHANNEL_ID`.
- `CHANNEL_URL` — публичная ссылка или invite-link для кнопки «Подписаться».
  Нужна, если идентификатор канала числовой (`-100...`): из такого id рабочую
  ссылку автоматически не построить.
- `DATA_DIR` — куда складывать файлы состояния (`state.json`, `stats.json`,
  `submissions.json`, `fsm.sqlite3`, `renders.sqlite3`). По умолчанию рядом с
  кодом. На хостингах, где код при
  каждом деплое перезаписывается из репозитория, укажи путь на постоянный том
  (на [bothost.ru](https://bothost.ru/) это `/app/data`), иначе колоды фраз,
  статистика и очередь предложки будут обнуляться при каждом пуше.

## Как пользоваться

После `/start` бот показывает основную клавиатуру:

- **✍️ Добавить фразу** — бот спросит текст, ты его присылаешь, и фраза уходит
  админу на модерацию. Одобренные попадают в `phrases_user.txt` и дальше
  выпадают любому пользователю наравне с основной базой. Можно с `|` для разделения на верх/низ:
  `я узнал|что бот теперь умнее меня`. Без `|` весь текст встанет вниз мема.
- **🖼 Свой мем** — бот попросит сначала фото, потом текст, и соберёт мем
  именно с этим текстом на этом фото (не рандомная фраза из базы). Этот режим
  намеренно остаётся простым: три знакомых шрифта и фиксированные верх/низ,
  без автоматического анализа кадра и цветных панчей.
- **💬 Создать фейк-переписку** — пошаговый конструктор переписки.
- **📮 Предложить в канал** — заявка на ручную модерацию и публикацию.
- **🧩 Мои стикерпаки** — создание и пополнение личных стикерпаков.
- **❓ Помощь** — напомнить, что бот умеет.

Во время пошаговых сценариев появляется
кнопка **✖️ Отмена** — жмёшь и возвращаешься в обычный режим.

Просто отправленное фото (без нажатия кнопок) — это по-прежнему быстрый путь
получить случайный мем со случайной фразой из базы.

Под готовым случайным мемом доступны четыре варианта новой подписи на той же
картинке:

- **🎲 Другая подпись** — общая колода со всеми категориями;
- **🤡 Сделай абсурднее** — сюр, животные, предметы с полномочиями и бытовой бред;
- **☠️ Сделай жёстче** — принудительно выбрать грубую лексику и мат;
- **🧠 Сделай интеллектуальнее** — философия, наука и псевдоучёный пафос.

У общей выдачи и каждой категории собственная перемешанная колода: фраза не
повторится, пока пользователь не пройдёт выбранную колоду целиком. Первая
генерация по присланной фотографии тоже использует общую базу. Старые кнопки
«Попробуй ещё» продолжают работать после обновления.

Команды для тех, кто любит текстом, а не кнопками:
- `/add текст` — то же самое что кнопка "Добавить фразу", но одним сообщением
- `/reset` — сбросить очередь показанных фраз для этого чата (иначе бот сам
  не повторяет фразы, пока не пройдёт всю базу целиком)

Количество фраз в базе нигде пользователю не показывается (ни в /start,
ни где-либо ещё) — это внутренняя техническая деталь, юзеру она не нужна.

Немного визуального рандома при каждой генерации:
- бот ищет лица и менее загруженные участки фотографии; найденное лицо получает
  жёсткий запрет на перекрытие, а предполагаемая фигура человека — мягкий штраф;
- текст может встать в свободную верхнюю, среднюю, нижнюю или боковую зону;
- панчлайн иногда выделяется жёлтым, голубым, розовым или кислотно-зелёным;
- случайная выдача выбирает один из пяти кириллических шрифтов;
- если фраза идёт одним блоком (без `|` на верх/низ), у неё три исхода:
  остаётся внизу, переезжает наверх, либо режется примерно пополам по
  словам — половина наверх, половина вниз (как в старых мемах);
- размер шрифта каждый раз чуть гуляет (±12%), как и толщина обводки;
- отступы от краёв тоже небольшие, но случайные.

Весь анализ происходит внутри процесса бота: фотография не отправляется во
внешний ИИ-сервис. Если OpenCV не загрузился или анализ упал, генератор не
ломается, а использует прежнюю раскладку сверху/снизу.

Так одна и та же фраза на разных фото (или два прогона одной и той же
фразы) выглядят по-разному, а не выходят как под копирку.

## Как пополнять базу фраз

Три способа:
1. Через кнопку "✍️ Добавить фразу" прямо в боте — доступно любому юзеру,
   но фраза появится в базе только после одобрения админом.
2. Командой `/add текст` — так же через модерацию.
3. Руками в `phrases.txt` (можно скриптом, можно вручную) — бот перечитывает
   файл при каждом новом фото, перезапускать не надо.

Формат файла:

```
фраза одним блоком снизу
верхняя часть|нижняя часть
```

Строки, начинающиеся с `#`, и пустые строки игнорируются — можно оставлять
комментарии/разделы.

Логика "не повторяться" реализована через файл `state.json` (создаётся
автоматически) — для каждого чата и каждой категории хранится своя
перемешанная и не пройденная до конца колода индексов фраз. Как только состав
категории меняется, только её колода пересобирается автоматически. Старый
формат `state.json` мигрирует без ручных действий.

## Как устроен генератор фраз (и почему теперь без "ИИ-слопа")

`generate.py` — комбинаторный генератор: банки слов ("паника", "выгорание",
"внутренний бардак", "синдром самозванца"...) и больше 60 разных шаблонов
("это не X, это Y", "он мечтал X, получил Y", метафоры "X — это как Y, только
Z", ток-шоу цитаты, корпоративный жаргон, посты в стиле имиджборда, псевдо-
объявления, псевдо-квитанции, псевдо-опросы и т.д.) собираются в уникальные
сочетания — **но у каждого шаблона отдельно прописан потолок** (`cap` в
списке `SIMPLE_TEMPLATES` и в `GEN_ENTRIES`), обычно 20-45 штук. Если весь
объём в 3000+ фраз нужен снова — либо подними лимиты (`cap`) у существующих
шаблонов, либо (что даёт лучший результат) допиши ещё десяток-другой новых
шаблонов с низким лимитом каждый, чтобы разнообразие росло вместе с объёмом,
а не терялось. Род и падеж согласуются программно, поэтому ошибок вроде
"паника взял ипотеку" не бывает.

## Ограничение размера и защита от спама

Сейчас бот отвечает любому пользователю без ограничений, включая добавление
фраз через кнопку/команду — это может быть проблемой для публичного бота с
большой аудиторией (кто-то накидает мусора в базу). Если понадобится — легко
добавить:
- rate limit (например, через `aiogram` middleware, не более 1 действия в N секунд)
- список разрешённых чатов/юзеров
- модерацию: добавленные через кнопку фразы сначала попадают в отдельный
  файл на ревью, а не сразу в общую базу
- ограничение `/add` и кнопки "Добавить фразу" только для админов

- Инлайн-режим (`@bot_username` в любом чате без добавления бота)
